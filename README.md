# TDD — таможня даёт добро!

Программа для обработки таможенных Excel-файлов. Исходники остаются на месте, результаты сохраняются отдельными файлами.

| Пункт меню | Что делает |
|---|---|
| **1. Сжатие** | Объединяет одинаковые артикулы, суммирует количество, вес и стоимость. По умолчанию выбран режим **с долями** |
| **2. Очистка** | Удаляет начальные апострофы и заменяет `D` на точку в столбцах цены и веса |
| **3. Объединение** | Собирает листы `PL INV …` в один лист «Общий» |
| **4. DIESEL** | Заполняет код ТН ВЭД, номер сертификата и дату по сезонному заказу |
| **5. Настройки** | Позволяет изменить режим сжатия, архивирование и движок записи таблиц |
| **6. Статистика** | Показывает файлы в рабочих папках |
| **0. Выход** | Закрывает программу |

## Как запустить на Windows

### 1. Установите Python — один раз

1. Откройте [страницу Python 3.13.16](https://www.python.org/downloads/release/python-31316/#files).
2. Внизу страницы скачайте **Windows installer (64-bit)**.
3. Запустите установщик, отметьте **Add python.exe to PATH** и нажмите **Install Now**.

Если Python 3.13 уже установлен, переходите к следующему шагу.

### 2. Скачайте программу

1. Откройте [репозиторий TDD](https://github.com/wardlive/TDD). Для приватного репозитория нужен вход в GitHub под аккаунтом с доступом.
2. Нажмите зелёную кнопку **Code → Download ZIP**.
3. Щёлкните по скачанному архиву правой кнопкой и выберите **Извлечь всё**.
4. Откройте распакованную папку **TDD-main**, в которой находятся `main.py` и `requirements.txt`.

Программу нужно запускать из распакованной папки, а не из ZIP-архива.

### 3. Настройте программу — один раз

В открытой папке щёлкните по адресной строке Проводника, напишите `cmd` и нажмите **Enter**.

В появившемся окне выполните по очереди две команды:

```bat
py -3.13 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Дождитесь окончания установки. Для этого шага нужен интернет. После завершения окно можно закрыть.

### 4. Запускайте двойным щелчком

Откройте файл **`run.bat`** в папке программы. Его же можно вынести на рабочий стол **ярлыком**; сам файл оставьте рядом с `main.py`.

На Windows выбор выполняется **цифрой и Enter**. Для нескольких файлов введите номера через запятую, например `1,3,4`. В подменю `0` возвращает назад, в главном меню — закрывает программу.

Повторять установку при каждом запуске не нужно. Для обработки Excel-файлов интернет не требуется.

## Куда положить файлы и где искать результат

При первом запуске программа сама создаст рабочие папки:

| Папка | Назначение |
|---|---|
| `data/input/` | Сюда можно положить файлы для обработки |
| `data/output/` | Здесь будут готовые файлы и отчёты DIESEL |
| `data/intermediate/` | Промежуточные таблицы расчёта долей |
| `data/archive/` | Копии обработанных исходников, если включено архивирование |

Можно также выбрать **«Другая папка или полный путь»** и работать с файлами в любом удобном месте.

Поддерживается формат **`.xlsx`**. Старый `.xls` сначала пересохраните в Excel как `.xlsx`. Временные файлы Excel, начинающиеся с `~$`, пропускаются.

## Как обработать DIESEL

1. Выберите **4. DIESEL**.
2. На первом шаге выберите эталон — сезонный заказ DIESEL.
3. На втором шаге выберите одну или несколько спецификаций для заполнения.
4. Дождитесь результата и откройте готовые копии в `data/output/`.

Программа читает лист эталона **«Спецификация исходная»**. В спецификации используется лист **«нач»**; если такого имени нет, подходит книга с единственным листом. Данные начинаются со строки 3.

Сопоставление выполняется по **буквам столбцов**, названия заголовков значения не имеют:

| Данные | В эталоне | В спецификации |
|---|---|---|
| Артикул | B | A |
| Размер | K | L |
| Код ТН ВЭД | J | I |
| Номер сертификата | AD | AC |
| Дата от | AE | AD |

Сначала ищется точный артикул. Если его нет, убирается последний суффикс после `_` и проверяется размер. Например, `Y03799P7389_900`, размер 38, сопоставляется с `Y03799P7389`, размер 38. Если у точного артикула разные данные, размер также помогает выбрать нужную запись.

**Ненайденные, неоднозначные или неполные данные не подставляются.** Такие строки остаются без изменений, а причина записывается в файл **`.issues.csv`** рядом с результатом. Этот отчёт можно открыть в Excel. Если не заполнена ни одна строка, создаётся только отчёт.

При обработке DIESEL сохраняются остальные ячейки, оформление, листы, формулы и их сохранённые результаты.

## Что важно при других операциях

- **Сжатие:** заголовки должны быть в строке 2, артикул — в A. Количество берётся из K, вес нетто — из N, вес брутто — из Q, стоимость — из T, размеры — из L, коробки — из V. Режим с долями записывает долю в O, округление — в P, заменяя прежнее содержимое этих двух столбцов. Результат — отдельная сводная таблица без исходного оформления.
- **Очистка:** обрабатывается первый лист начиная со строки 2. Столбцы цены и веса ищутся по заголовкам первой строки; если не найдены, используются AB, AJ и AK. Формулы и остальные листы сохраняются.
- **Объединение:** создаётся лист «Общий». Если он уже был, он заменяется в копии результата. Исходные листы остаются.
- **Настройки:** действуют до закрытия программы. При следующем запуске снова используется сжатие с долями. Выбор `openpyxl` / `xlsxwriter` влияет только на запись сжатых таблиц.

## Если что-то не получилось

- **`py` не найден:** установите Python по шагу 1 и заново откройте командную строку.
- **`No suitable Python runtime found`:** требуется Python 3.13; установите его по шагу 1.
- **Ошибка установки библиотек:** проверьте интернет и повторите вторую команду из шага 3.
- **`ModuleNotFoundError`:** повторите установку библиотек из шага 3.
- **Файлов нет в списке:** проверьте папку и расширение `.xlsx` либо укажите полный путь.
- **Ошибка доступа к результату:** закройте этот файл в Excel и повторите операцию.
- **Другие ошибки:** подробности записываются в `data/tdd_suite.log`.
