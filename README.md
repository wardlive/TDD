# 🚀 TDD-Suite v3.0

Комплексная система обработки Excel файлов с модульной архитектурой.

## 🎯 Возможности

- **Сжатие спецификаций** - простое и с расчетом долей в коробках
- **Очистка файлов** - удаление апострофов и замена символов
- **Объединение листов** - слияние PL INV листов
- **Заполнение артикулов** - автоматическое заполнение данных
- **Пакетная обработка** - обработка множества файлов

## 🚀 Быстрый старт

1. Установите зависимости:
pip install -r requirements.txt


2. Запустите систему:
python main.py


3. Поместите файлы в папку `data/input/` и используйте интерактивное меню.

## 📁 Структура папок

- `data/input/` - входные файлы
- `data/output/` - результаты обработки
- `data/intermediate/` - промежуточные файлы
- `data/archive/` - архив обработанных файлов

## 🎮 Использование

Система предлагает интуитивное интерактивное меню для всех операций:

1. Сжатие спецификаций (простое или с долями)
2. Очистка файлов
3. Объединение листов
4. Заполнение артикулов
5. Пакетная обработка
6. Настройки системы
